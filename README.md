# Тестовое задание ТОЛЬКООПТ

Колесников Артур

Исправил функцию расчёта клиентской цены по предложениям конкурентов и добавил два автоматических теста. Сохранил исходный интерфейс и порядок применения правил из задания.

## Требования

Для запуска нужен Python 3.10 или новее. Использовал только стандартную библиотеку.

## Запуск

Выполнить команды из каталога с файлами проекта.

### Запустить тесты

```
python -m unittest -v
```

### Запустить пример

```
python starter.py
```

Ожидаемый результат примера содержит цену `Decimal("4728.00")` и решение `APPLY`.

## Что исправил

В функции `recommend_price` реализовал следующие правила.

- Ограничил ожидание источника параметром `timeout_s`. При исключении, тайм-ауте или статусе, отличном от `success`, предусмотрел возврат текущей цены и `HOLD`.
- Исключил предложения с неизвестной доставкой или сроком более 6 дней, а также предложения `MYSHOP` независимо от регистра.
- Сохранил текущую цену при отсутствии подходящих предложений, даже если она ниже `min_price`.
- Заменил вычисления через `float` на `Decimal`. Реализовал снижение минимальной цены конкурента на 1,5%, округление вниз до копейки и ограничение результата снизу значением `min_price`.
- Добавил проверку отклонения итоговой цены от текущей. Изменение более чем на 30% в любую сторону возвращает `REVIEW`, остальные случаи возвращают `APPLY`. Ровно 30% допускается.

Решение `REVIEW` требует ручного согласования перед применением цены.

## Тесты

В `test_starter.py` добавил два автоматических теста на `unittest`.

- В обычном расчёте проверил фильтрацию предложений, доставку ровно 6 дней, округление вниз, тип `Decimal` и решение `APPLY`.
- В сценарии тайм-аута проверил сохранение текущей цены ниже минимума и решение `HOLD`. Добавил внешнее ограничение ожидания, чтобы при ошибке в обработке тайм-аута тест завершался с ошибкой, а не зависал.

Для проверок использовал имитацию асинхронного источника по условию задания.
